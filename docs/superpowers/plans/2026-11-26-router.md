**Goal:** Add a confirmatory pre-generation router (k in {1,4}) with max-reuse without harming validity.

**Architecture:** New frozen prereg `prereg/qc_router_prereg.md` + new eval frame `qc_router_eval` (1000 fresh, disjoint from all). Train CPU-only on P1, tune threshold on `qc_fresh`, evaluate once on `qc_router_eval` with fixed per-depth block costs. One new GPU run (`squad_qwen4b_qc_router`, ~0.8-1h).

**Tech Stack:** Python 3.12, `src/rag_energy` (`blocks`, `stats/policy`, `retrieval/index`), TOML configs, NVML block protocol (120s cooldown, 5x200 disjoint), seed 20261115.

**Spec:** `ROADMAP.md` Phase 8 router section (6-9 GPU-h, H-route, 30% capture + 2pp margin), `prereg/qc_prereg.md` (frozen, do not edit), `docs/PHASE8_PLAN.md`, `docs/DECISIONS.md` D-034/D-035, `analysis/policy/policy.json` (P3 -9.8% baseline).

- Python 3.12 at `C:\ProgramData\anaconda3\python.exe`; conda env `energy-optimal-rag`; single RTX 3060 6GB, batch size 1, no concurrent jobs.
- Seeds from config, never literals in functions; energy in J, accuracy in [0,1], depths integers.

- No wall meter (waived D-031/A-004); GPU energy from NVML only; absolute J is a range, ratio is reportable.
- Max-reuse rule: P1=train only, `qc_fresh`=threshold-select only, `qc_router_eval`=once-only eval. Never train on eval IDs.

## Review Focus

- Leakage via reused qids (eval IDs seen in train/select) — expect disjointness check to fail loudly, not silently pass.
- Per-query energy noise reintroduced as router signal (the 7.21% artifact) — expect fixed per-depth block costs, not per-query windows.
- Threshold tuned on eval set — expect threshold frozen on `qc_fresh` before eval run exists.
- Thermal/idle drift invalidating block comparison — expect 120s cooldown, idle from cooldown tail, idle CV<=0.20 gate, PROTOCOL tag.
- Power/accuracy gate re-thresholded post-hoc — expect frozen 30% capture + 2pp margin rule applied as-written.
